# Credits, not payments, at pilot

Requests carry budgets and revenue shares are computed and recorded, but no external
money moves: all value is internal **Credits** recorded in a double-entry Ledger.
Payment-gateway compliance (KYC, chargebacks, refunds) adds no learning at pilot
stage, while ledger-based credits keep the full pricing/split machinery testable.
A payment gateway can settle the ledger later without redesign.
